# SnowLinux

**English** | [日本語](#日本語)

A lightweight Linux distribution that aims to feel like Mac OS X 10.4 (Tiger) – 10.6 (Snow Leopard), for people who used those systems and for the old hardware that deserves a safe, modern kernel.

> **Status: early development.** There is no bootable ISO yet. What is here today are the plan, the themes, the default configuration and the scripts used to build and test them.

## Goals

- **Snappy above all.** Everyday operation (mouse, opening apps, opening a folder full of photos) must stay fast on old machines. Heavy jobs such as exporting or filtering may take as long as the hardware needs, but they must not make the desktop stutter.
- **Familiar and a little nostalgic.** Someone who used Tiger – Snow Leopard should feel at home: menu bar, Dock, traffic-light buttons, Finder-like file manager, a System Preferences-like settings app.
- **Focused.** Web, YouTube, viewing and organizing photos, light to serious photo editing, and everyday office documents. Not a gaming or music-production machine.
- **Two editions.** x86_64 first (based on MX Linux, Xfce), then PowerPC Macs (Debian ports). Themes, configuration and tools are shared.

## What is in this repository

| Folder | Contents |
|---|---|
| `docs/plan.md` | The plan and decisions |
| `docs/apps.md` | Which applications to keep, move to Utilities, or remove |
| `docs/history.md` | Work log (in Japanese) |
| `themes/` | xfwm4 window theme (generated by `themes/tools/gen_xfwm4.py`) |
| `config/` | Default settings that go into `/etc/skel` (menu bar, Dock, fonts, autostart cleanup) |
| `scripts/` | Helper scripts for testing on a spare user account |

## Trying it

Developed on MX Linux 25 (Xfce). Create a spare user, apply the settings, log in as that user:

```
sudo adduser snowtest
sudo scripts/apply-to-snowtest.sh --reset
```

Needs `plank`, `xfce4-appmenu-plugin` and `appmenu-gtk3-module`.

## 日本語

Mac OS X 10.4 (Tiger) 〜 10.6 (Snow Leopard) の操作感を目指す、軽量な Linux ディストリビューションです。当時の Mac を使っていた人と、安全で新しいカーネルを必要とする古いハードウェアのためのものです。

> **現状: 開発の初期段階です。** 起動できる ISO はまだありません。計画、テーマ、初期設定、テスト用のスクリプトがあります。

### 目標

- **何よりもキビキビ。** 普段の操作 (マウス、アプリの起動、写真の多いフォルダを開く) は、古い機械でも速く。書き出しやフィルターのような重い処理は機械の性能なりに時間がかかってよいが、操作を止めない。
- **違和感がなく、ちょっと懐かしい。** メニューバー、Dock、信号機ボタン、Finder 風のファイルマネージャー、システム環境設定風の設定アプリ。
- **目的を絞る。** ネット閲覧、YouTube、写真の閲覧と整理、ちょっとした〜少し本格的な写真編集、仕事の書類づくり。ゲームや音楽制作は目指しません。
- **2 つのエディション。** まず x86_64 版 (MX Linux / Xfce ベース)、次に PowerPC Mac 版 (Debian ports)。テーマ・設定・ツールは共通です。
