# SnowLinux

Mac OS X 10.6 Snow Leopard の操作感と見た目を目指す、軽量な Linux ディストリビューション。

- ベース: MX Linux (Xfce)
- ISO 作成: MX Snapshot
- 方針: Apple の素材 (アイコン・壁紙・フォント・ロゴ) は使わず、雰囲気の似た自作素材で作る

詳細は [docs/plan.md](docs/plan.md) を参照。

## フォルダ構成

- `themes/` — GTK / xfwm4 / Plank のテーマ
- `config/` — `/etc/skel` に入れる初期設定 (パネル配置など)
- `assets/` — 自作の壁紙・アイコン
- `docs/` — 計画とメモ
