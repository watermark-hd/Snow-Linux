# 機能の行き先表

MX Linux (Xfce) は、見た目と機能のバランスがよい。見た目だけを Mac に寄せると、MX にあった機能が隠れたり消えたりして、使いにくくなる。
そこで、**MX / Xfce の機能を 1 つずつ書き出して、SnowLinux のどこに行くのかを決める**。行き先のない機能は、削らない。

進め方のルール:

- 隠す・消す機能には、必ず別の入口を用意する (この表の「行き先」)
- 「使いやすくなるなら思い切って機能を入れる」(絶対条件) → Mac にない機能でも、あったほうが使いやすければ入れる。Mac のやり方 (見た目・操作) に合わせた入口にする
- 状態: ✅ できている / 🔧 作業中・一部 / ⬜ これから

| MX / Xfce の機能 | 行き先 (SnowLinux) | 状態 |
|---|---|---|
| アプリメニュー (Whisker。名前で検索して起動) | Spotlight 風のランチャー (Ctrl+Space)、アプリケーションフォルダ、Dock | 🔧 ランチャーの最初の版 (アプリと開いているウィンドウ。ファイルも同じ一覧に出る。GTK の自作で、日本語入力可) |
| タスクバー (開いているウィンドウの一覧) | Dock の起動中インジケーター、ウィンドウメニュー、Exposé 風の一覧 | 🔧 Dock + Exposé 風の一覧 (F9、最初の版) |
| システムトレイ (Wi-Fi・音量・電池・Bluetooth) | メニューバー右側の「メニューエクストラ」 (今は Xfce の標準のまま) | 🔧 |
| ワークスペース (仮想デスクトップ) | Spaces (Ctrl+矢印で切り替え、一覧表示) | 🔧 最初の版 (F8 で一覧。切り替えは Ctrl+F1〜F4 / Ctrl+Alt+矢印) |
| ウィンドウを画面の端に寄せて並べる (スナップ。Windows ユーザーに便利) | 緑のボタン (拡大) と、ドラッグでスナップ。Mac にない機能だが、残す | ⬜ |
| MX ツール (スナップショット、パッケージ、ブート修復など) | アプリケーション > ユーティリティ | ✅ |
| Xfce の設定マネージャー (ディスプレイ、キーボード、マウス、外観...) | システム環境設定 (自作 `snowlinux-system-preferences`)。Mac の項目の並び (個人設定・ハードウェア・ネットワーク・システム) に合わせる。埋め込める Xfce の設定は同じウィンドウの中に出す | 🔧 最初の版 (28 項目) |
| デスクトップの右クリックメニュー | Mac と同じ項目 (新規フォルダ、情報を見る、背景を変更...) | ⬜ |
| パネルの電源・ログアウト・ユーザー切り替え | ロゴ (雪の結晶) のメニュー | 🔧 最初の版 (ロゴを押すとメニュー。強制終了は Ctrl+Alt+Esc)
| ファイルマネージャー (Thunar: タブ、ツリー、検索、右クリックの操作) | Finder 風に。タブ・ツリーはそのまま残す。カラム表示とサイドバーの見出しを足す | 🔧 |
| クリップボード履歴 (Clipman。Windows の Win+V に近い) | 残すかどうか決める。Mac にないが、あれば便利 (オプション) | ⬜ 今は自動起動を止めている |
| ファイル検索 (Catfish) | Spotlight 風のランチャーに統合 (ホームは find、そのほかは plocate) | 🔧 最初の版 |
| 通知 | 右上に出る通知 (Mac 風の見た目) | 🔧 見た目が未調整 |
| アップデート (MX アップデータ) | 「ソフトウェア・アップデート」 | ⬜ 今は MX のまま |
| スクリーンショット | ⌘Shift+3 / 4 (Ctrl+Shift+3 / 4) など、Mac と同じ操作 | 🔧 最初の版 (Ctrl+Shift+3 / 4、クリップボードは Ctrl+Alt+Shift+3 / 4) |
| 日本語入力 (fcitx + Mozc) | **fcitx 5 + Mozc に移す** (Qt6 のアプリでも日本語が入る)。メニューバー右側に表示。切り替えは 半角/全角 や 英数・かな キー | 🔧 fcitx 4 は Qt6 のアプリ (FeatherPad など) で動かない |
| プリンター設定 | システム環境設定 > プリンター | 🔧 (今は MX / CUPS の画面を別のウィンドウで開く) |
| ディスプレイの色 | ディスプレイ調整アプリ (自作。必須) | 🔧 最初の版 (縞と円、3 段階 × 赤緑青) |
| USB の取り出し | Finder のサイドバーの取り出しボタン | ⬜ 今は MX の USB アンマウンタ |
| ゴミ箱を空にする | Finder のメニューと Dock のゴミ箱の右クリック | 🔧 |
| 起動画面・ログイン画面 | 自作 (素材ができている) | 🔧 まだ入れていない |
| ウィンドウの切り替え (Alt+Tab) | アプリの切り替え (Alt+Tab のまま) と、同じアプリのウィンドウ切り替え (Alt+`) | 🔧 最初の版 (自作。アプリの帯を出す) |
| ターミナル | ユーティリティ > ターミナル | ✅ |

## これから書き足す

- 起動時のサービスやデーモン (Bluetooth、プリンター、スキャナー)
- 右クリックメニューの項目 (Thunar)
- キーボードショートカット (Xfce の標準にあるもの)
- MX 独自の機能 (MX Tweak のオプションなど)
